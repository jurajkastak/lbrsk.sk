pod doménou **lbrsk.sk**.

- `index.html` — celý web (jedna stránka, štýly vnútri)
- `favicon.svg`, `logo.svg` — logo 7A (osmička v červenom bloku, #A50F1A)
- `404.html`, `robots.txt`, `sitemap.xml`, `CNAME`
